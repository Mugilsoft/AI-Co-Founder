# Memory Store: Technical Architecture & Standards

## 1. Approved Technology Stack

### Frontend & UI
- React.js / Vite / Next.js
- TypeScript / Modern JavaScript (ES6+)
- Vanilla CSS / HSL Tailored Color Tokens (TailwindCSS optional upon request)
- Responsive, Accessible, and Mobile-First Layouts

### Backend & Microservices
- Node.js (Express / Fastify) / Python (FastAPI / Flask)
- REST APIs & gRPC
- PostgreSQL / Redis / BigQuery / Cloud Storage

### AI, ML & RAG Pipeline
- LLM Providers: Google Gemini / Anthropic Claude / OpenAI
- Vector DBs: Qdrant / Pgvector / ChromaDB
- Frameworks: LangChain / LlamaIndex / Custom Orchestration Engine

## 2. Coding & Quality Directives
- **Architecture**: Modular, Clean Code Architecture.
- **Security**: Zero hardcoded secrets, input sanitization, OAuth 2.0 / JWT auth.
- **Testing**: Minimum 80% coverage on core logic modules.
